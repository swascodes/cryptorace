# 💫 Wishing Well — A Decentralized Luck & Hope Experiment

> *"Drop a wish into the blockchain... and maybe it echoes back."*
>


## 📝 Project Overview

Wishing Well is a **smart contract** that lets users make wishes by sending ETH into a decentralized “well.”  
Each wish has a small, random chance to be **granted**, rewarding the sender with **double their ETH**.  
Every wish and outcome is recorded on-chain, ensuring **transparency, fairness, and permanence**.

This project is an experiment at the intersection of **blockchain randomness, gaming, and interactive art**.

## ⚡ Features

- 🪙 **Make a Wish:** Users send ETH with a message.  
- 🎲 **Random Reward:** ~10% chance to double the sent ETH.  
- 📜 **On-chain Storage:** Every wish is permanently logged.  
- 👑 **Owner Functions:** Deposit and withdraw funds securely.  
- 💡 **Educational Design:** Demonstrates randomness, payouts, and event logging.

## 💻 How to Interact

1. Open [Remix IDE](https://remix.ethereum.org/).  
2. Paste the Solidity code and compile with version `0.8.20`.  
3. Connect to **Flow EVM Testnet** via MetaMask.  
4. Deploy the contract.  
5. Use `makeWish(string memory message)` to send a wish and ETH.  
6. Check your luck via the emitted events or `getAllWishes()` if implemented.
